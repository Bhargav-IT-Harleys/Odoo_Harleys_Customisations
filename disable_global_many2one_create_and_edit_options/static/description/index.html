Disable Many2One Create/Edit Options

This module globally disables the "Create" and "Create and Edit" options in all many2one fields across Odoo 19 Enterprise. It ensures a cleaner UI and prevents accidental record creation.

🔍 Before vs After Comparison

See how this module transforms the user experience by removing clutter and enforcing clean data selection:

❌ Before Installation

Users can create new records directly from dropdowns, leading to:

  • Duplicate or incomplete entries
  • Inconsistent data across modules
  • Uncontrolled record creation

✅ After Installation

Dropdowns now only show existing records. Benefits include:

  • Cleaner UI and dropdowns
  • Controlled data entry
  • Improved user experience

⚙️ Installed Features

  • Globally disables "Create" and "Create and Edit" in many2one fields
  • Works across all modules without modifying views
  • Built using OWL registry patch for clean override
  • No menus, views, or reports added
